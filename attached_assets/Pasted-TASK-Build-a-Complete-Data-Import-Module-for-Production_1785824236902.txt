FINAL REQUIREMENT
====================================================

This module must be production-grade and suitable for importing historical data into a completely fresh ERP database where only the Item Master exists. During import, the system should intelligently create missing Customers, Vendors, and Ledgers by prompting the user, assign them to the correct ledger groups, post all accounting entries automatically, allocate receipts/payments against invoices, create advances when required, and ensure that every imported transaction is reflected correctly in Inventory, Customer/Vendor Ledgers, Cash Book, Bank Book, Journal, Day Book, Trial Balance, Profit & Loss, Balance Sheet, Dashboard, GST Reports, and all financial reports. The import process must include sample templates, validation, preview, error reporting, import history, and rollback to make migration from the old ERP safe and reliable.
