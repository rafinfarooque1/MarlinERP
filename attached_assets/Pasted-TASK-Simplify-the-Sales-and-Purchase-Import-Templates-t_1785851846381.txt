TASK: Simplify the Sales and Purchase Import Templates to match ERP data entry.

The current Sales and Purchase import templates ask for too many fields. This makes importing old ERP data difficult. The import should behave exactly like manual entry in the ERP.

==========================================================
SALES IMPORT
==========================================================

The Sales Import should only ask for the minimum required fields.

Keep only the following columns:

• Invoice No (Optional)
  - If blank, auto-generate invoice number.

• Date *

• Location *

• Customer Name *
  - If customer does not exist, ask during import whether to:
    1. Create new customer
    2. Map to existing customer

• GSTIN (Optional)
  - If customer is new, save GSTIN.

• Item Name *
  - Match against Item Master.
  - If item not found, stop import and show validation.

• Quantity *

• Unit (Optional)
  - If blank, use Item Master default unit.

• Price *
  - This is the selling MRP / selling price.

• Discount (Optional)
  - Per unit discount.
  - Default = 0.

• Bill Discount (Optional)
  - Default = 0.

• Payment Status
  - Paid
  - Partial
  - Unpaid

• Paid Amount
  - Required only if Paid or Partial.
  - If blank:
      Paid → use Grand Total
      Partial → validation error
      Unpaid → 0

• Payment Account (Optional)
  - Cash
  - Bank
  - UPI
  - Customer Credit

• Reference (Optional)

• Narration (Optional)

==========================================================
GOAL
==========================================================

The import template should be as simple as manual ERP entry.

The user should only provide business information.

The ERP should automatically generate all accounting, GST, ledgers, vouchers, stock movements, inventory valuation, receivables, payables, and journals exactly as the manual Sales and Purchase modules already do.

There must be NO difference between:
• Manual Sale vs Imported Sale
• Manual Purchase vs Imported Purchase

Both should create identical accounting entries and reports.
