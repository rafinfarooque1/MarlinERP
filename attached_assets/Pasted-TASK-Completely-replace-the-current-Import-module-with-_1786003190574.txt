TASK: Completely replace the current Import module with a professional ERP Migration Import Wizard. The current import module should be removed and redesigned. Do NOT create a separate migration module. Modify the existing Import module.

====================================================================
OBJECTIVE
====================================================================

The Import module should allow complete migration from another ERP using Excel files.

The system should not immediately import data.

Instead, it should guide the user through:

Upload
→ Analyse
→ Manual Mapping
→ Demo Import
→ Financial Verification
→ Approval
→ Production Import

The objective is to ensure that the imported ERP books exactly match the old ERP before committing anything to the production database.
