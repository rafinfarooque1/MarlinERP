SALES IMPORT
====================================================================

The uploaded sales file contains the ACTUAL selling price.

Example

Item Master MRP = ₹250

Old ERP Selling Price = ₹240

Do NOT reject the invoice.

Instead

Price = ₹250

Discount = ₹10

Invoice Value = ₹240

If selling price is above Item Master MRP

Example

MRP = ₹250

Old ERP Selling Price = ₹260

Increase selling price to ₹260

Discount = 0

Exactly like manual ERP Sales Entry.

This ensures imported invoices behave exactly like manually created invoices.
