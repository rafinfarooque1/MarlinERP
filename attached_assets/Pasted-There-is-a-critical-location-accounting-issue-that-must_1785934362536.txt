There is a critical location-accounting issue that must be fixed across the ERP.

CURRENT ISSUE

When an Admin or Head Office user is working on behalf of another location (Warehouse/Outlet) and creates any accounting transaction, the voucher is sometimes posted under Head Office or All Locations instead of the selected location.

As a result:

- The transaction is visible in All Locations.
- The transaction is visible in Head Office.
- But it does NOT appear correctly when viewing the individual location.
- That location's Dashboard is incorrect.
- That location's Ledgers are incorrect.
- That location's Cash/Bank balances may be incorrect.
- Reports become inconsistent.

This must NEVER happen.

==================================================
REQUIRED BEHAVIOUR
==================================================

The selected transaction location must ALWAYS become the accounting location.

If the user selects:

Frozen Hub - Ragiguda

then ALL accounting entries generated by that transaction must belong to Ragiguda.

NOT Head Office.

NOT All Locations.

Exactly Ragiguda.

Likewise for:

- Calicut
- Warehouse
- Head Office
- Any future location
