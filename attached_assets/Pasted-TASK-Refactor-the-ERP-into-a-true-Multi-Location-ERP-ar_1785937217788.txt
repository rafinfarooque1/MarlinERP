TASK: Refactor the ERP into a true Multi-Location ERP architecture with strict location-based accounting and independent user permissions.

This is a core architectural improvement. Before implementing, review the existing location, permission, voucher, ledger, reporting, dashboard, stock, and accounting architecture. Reuse existing services wherever possible and do NOT create duplicate logic.

====================================================================
OBJECTIVE
====================================================================

The ERP must follow a true multi-location architecture.

Every location (Head Office, Warehouse, Outlet) should operate independently while sharing the same ERP.

Permissions and Accounting Location are TWO DIFFERENT CONCEPTS and must never be mixed.

• Permissions determine WHAT a user is allowed to do.
• Accounting Location determines WHERE the transaction belongs.

The creator of a transaction must NEVER decide the accounting location.

The SELECTED LOCATION always decides the accounting location.

====================================================================
1. PERMISSION MODEL
====================================================================

Warehouse User

Can:

✓ View own location
✓ Create transactions in own location
✓ Edit transactions in own location
✓ Delete transactions in own location
✓ View reports for own location

Cannot:

✗ Access another warehouse
✗ Access Head Office
✗ Edit another location's transactions

------------------------------------------------------------

Outlet User

Same behaviour.

------------------------------------------------------------

Head Office User

Head Office is a NORMAL location.

Can:

✓ Work only in Head Office

Cannot:

✗ Automatically own all accounting
✗ View warehouses unless granted permission

------------------------------------------------------------

Admin / Management

Admin can:

✓ Switch between any location

Head Office

Warehouse

Outlet

All Locations

Admin may create/edit/delete transactions for ANY location.

However,

Admin is ONLY acting on behalf of the selected location.

Admin permissions must NEVER force accounting into Head Office.
