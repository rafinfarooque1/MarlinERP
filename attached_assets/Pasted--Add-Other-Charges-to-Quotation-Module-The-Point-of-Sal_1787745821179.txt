

Add “Other Charges” to Quotation Module

The Point of Sale / Sales module already has a working “Other Charges” section. I need the same feature and UI behavior added to the Quotation module.

Reference

Use the existing POS Other Charges implementation as the source of truth.



In POS, below the Cart Items / Quoted Items section, there is:



Other Charges
Example: Packing / Delivery / Recovery, etc.



Each charge row contains:



Direct Income Ledger dropdown

Amount

Delete/remove button

Add Charge button for multiple charge rows



The exact same section should be added to the Quotation create and edit form, positioned below the Quoted Items section and before the Quotation Summary.

Functional Requirements

1. Add Other Charges section to Quotation

Add a section like:



Other Charges
Packing / Delivery / Recovery ... added to the quotation total



Each row must have:



Direct Income ledger selector

Amount input

Remove/delete button

Add Charge button to add multiple charges

2. Ledger restriction

For new quotation charges:



Show only active, postable Direct Income group ledgers

Do not show Expense, Sales, Asset, Liability, or other ledger groups

Follow the same validation rules already implemented in POS/Sales



Historical/legacy quotation charges, if any, should remain visible when editing without breaking old records.

3. Multiple Charges

The user must be able to add multiple charge rows.



Example:

₹200

4. Quotation Total Calculation

Charges must be added to the quotation total.



Formula:

Item Taxable Amount
- Bill Discount
+ CGST
+ SGST / IGST
+ Other Charges
= Quoted Total

Example:

Taxable Amount:      ₹1,000
GST:                   ₹180
Other Charges:        ₹100
--------------------------------
Quoted Total:       ₹1,280

Taxable Amount

GST

Other Charges

Quoted Total

  --------------------------
  Total Charges         ₹300

5. No GST on Charges

Follow the existing POS charge behavior:



Other Charges are post-tax

Charges should not have GST calculated separately

GST calculation applies only to the quoted items according to existing quotation rules



So:

Items + GST + Charges = Quotation Total

Do not alter the GST calculation of existing quotation items.

6. Save and Edit

Quotation charges must be fully persisted.



When creating a quotation:



Save all charge rows

Save selected ledger ID

Save ledger name/reference as required by the existing architecture

Save amount

Save total charges



When editing a quotation:



Existing charges must load correctly

Multiple charges must be editable

Users can add new charges

Users can remove charges

Changing charges must correctly recalculate the quotation total

Avoid duplicate charge rows after repeated edits
