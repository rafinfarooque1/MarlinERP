8. STOCK TRANSFER
==================================================

Fully audit the complete transfer lifecycle.

Transfer Out:

- lock source stock
- consume correct FIFO/FEFO lots
- reduce source stock
- write transfer_out ledger movement
- create reservation/in-transit quantity if required

Transfer In:

- lock transfer
- release corresponding reservation
- increase destination stock
- restore/transfer batch information
- write transfer_in ledger movement
- complete transfer

- destination receives actual quantity
- remaining quantity stays in transit

- write proper return movement
- maintain complete audit trail
