2. AUTOMATIC WAREHOUSE REGISTRATION
==========================================

Whenever a new Warehouse is created,

Automatically create a Rent record.

The user should not manually create the warehouse reference.

The Rent module should automatically list every warehouse.

If a warehouse is deleted or archived,

its Rent record should also become inactive.

==========================================

   ├── Chennai Warehouse

Also automatically create

Indirect Expenses

Rent Expense
   └── Warehouse Name

Example

Rent Expense
   ├── Bangalore Warehouse
   ├── Kerala Warehouse
   ├── Chennai Warehouse

These ledgers are SYSTEM GENERATED.

Users cannot create, edit or delete these ledgers manually.

If warehouse name changes,

ledger name should update automatically.
