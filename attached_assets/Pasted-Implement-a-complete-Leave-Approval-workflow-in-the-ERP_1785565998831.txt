Implement a complete Leave Approval workflow in the ERP.

Currently employees can apply for leave, but there is no approval module for managers or Head Office.

This must be a production-grade approval workflow.

==================================================
1. EMPLOYEE SIDE
==================================================

Keep the existing "Apply Leave" functionality.

Employee can:

• Apply Leave
• View Leave History
• View Status

Statuses:

Pending
Approved
Rejected
Cancelled

Employee cannot approve their own leave.

==================================================

==================================================

Create a new module:

HR
    → Leave Approvals

HR
    → Attendance
            → Leave Approvals

Visible only to users having permission.

This page should display:

Employee Name

Leave Type

==================================================
4. APPROVAL WORKFLOW
==================================================

When employee applies leave

Status = Pending

No payroll changes.

Approver clicks

Approve

Status becomes

Approved

Attendance automatically marks those dates as Leave.

Payroll calculations use approved leave only.

Reject

Status becomes

Rejected

Attendance returns to normal.

Cancelled

Employee may cancel only Pending requests.

==================================================
5. PERMISSION CONTROL
==================================================

Integrate with Permission Module.

Add new permissions:

Leave Approval

View Leave Requests

Approve Leave

Reject Leave

Only users having these permissions can access Leave Approvals.

Example

Head Office HR

✔ View

✔ Approve

✔ Reject

Warehouse Manager

Optional depending on permissions.

Normal Employee

No access.

==================================================

==================================================

Support approval hierarchy.

Example

Employee

Supervisor

Warehouse Manager

Head Office HR

Management

Allow choosing approval authority through permissions.

If company wants only Head Office approval

Only Head Office sees requests.

9. ATTENDANCE INTEGRATION
==================================================

Approved leave

Automatically marks attendance as Leave.

Pending leave

Does NOT affect attendance.

Rejected leave

Ignored.
