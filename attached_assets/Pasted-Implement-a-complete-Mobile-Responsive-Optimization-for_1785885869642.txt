Implement a complete Mobile Responsive Optimization for the ERP.

This ERP is heavily used for data entry, so mobile usability must be improved without removing any functionality.

=========================================================
1. Dashboard Mobile Layout
=========================================================

Keep the dashboard cards exactly like the attached mobile reference.

Display cards as:

Sales | Purchases

Expenses | Inventory Value

Cash Balance | Bank Balance

Receivables | Payables

GP | NP

Continue remaining widgets below.

Do NOT make one card per row.

Use a responsive 2-column grid.

Cards should have:
- equal width
- equal height
- larger numbers
- larger titles
- proper spacing
- proper padding
- no overlapping text

=========================================================
2. Mobile Tables
=========================================================

Tables are difficult to use.

Instead of squeezing every column,

keep desktop tables unchanged.

On mobile:

• Enable smooth horizontal scrolling

• Horizontal scroll must use native touch swipe

• Momentum scrolling on iPhone and Android

• Thin scrollbar always visible while scrolling

• Sticky first column wherever practical

Examples:

Sales
Purchase
Quotations
Customers
Vendors
Stock
Ledgers
Day Book
Cash Book
Bank Book
Voucher List
Reports

All tables must scroll smoothly sideways.

=========================================================

Allow smooth sideways scrolling.

Maintain desktop column widths.
