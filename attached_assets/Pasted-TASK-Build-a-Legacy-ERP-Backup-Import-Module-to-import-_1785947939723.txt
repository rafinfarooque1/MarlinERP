TASK: Build a Legacy ERP Backup Import Module to import an old ERP backup (ZIP containing DBF files) into the selected location in the current ERP.

This is a migration tool for one-time historical data import.

==========================================================
1. NEW MODULE
==========================================================

Create a new module:

Company
→ Data Migration
→ Legacy ERP Import

Only Management and Admin users should have access.

==========================================================
2. FILE UPLOAD
==========================================================

Allow uploading:

• ZIP backup files
• DBF files
• Multiple DBF files
• Legacy ERP backup folders

Supported format:

ZIP containing DBF tables.

==========================================================
3. LOCATION SELECTION
==========================================================

Before importing, ask:

Import Into Location *

Options

• Head Office
• Warehouse
• Outlet

If Warehouse or Outlet is selected:

Choose the exact location.

Example:

Frozen Hub - Ragiguda

Frozen Hub - Calicut

Head Office

All imported accounting, inventory and transactions must belong ONLY to the selected location.

==========================================================
4. PASSWORD HANDLING
==========================================================

When a ZIP is uploaded:

• Try extracting with a blank password first.
• If successful, continue automatically.
• If extraction fails, ask the user for the password.
• Retry extraction.
• If it still fails, show a proper error message.

==========================================================
15. ACCEPTANCE CRITERIA
==========================================================

The user should be able to upload a legacy ERP backup ZIP, select the destination location, preview the contents, import the required data, and have all accounting, inventory, and reports generated exactly as if the transactions had been entered manually into the ERP.

The importer must preserve accounting integrity, support historical data migration, and assign every imported record to the selected location.
