COMPREHENSIVE ERP HEALTH CHECK / PRODUCTION READINESS AUDIT

IMPORTANT:
Do NOT immediately modify, delete, migrate, or "fix" anything.

First perform a complete health check of the ERP system and compare the actual running application, backend, database, accounting logic, permissions, and reports.

The purpose is to determine whether the ERP is working correctly end-to-end in the LIVE/PUBLISHED environment.

This is a READ-ONLY AUDIT FIRST.

==================================================

==================================================

Check:

- Development/preview environment
- Published/live environment
- API server
- Web frontend
- Database connection
- Environment variables
- API/client version compatibility
- Build version
- Running bundle/version

- Pending migrations
- Failed migrations
- Runtime errors
- API errors

- Server errors
- Failed requests
- 404/401/403/500 responses

Verify that the LIVE published application is actually running the latest intended code.

33. CRITICAL ISSUE PRIORITY
==================================================

Classify findings:

P0 - CRITICAL
Can corrupt financial data, security, database, stock, accounting or production operation.

P1 - HIGH
Important business function broken or materially incorrect.

P2 - MEDIUM
Function works but has meaningful issue.

P3 - LOW
UI, usability, minor reporting or cosmetic issue.
