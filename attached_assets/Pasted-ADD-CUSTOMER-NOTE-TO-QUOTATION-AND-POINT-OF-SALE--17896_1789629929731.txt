ADD CUSTOMER NOTE TO QUOTATION AND POINT OF SALE
================================================

Add a "Note" field to both:

1. Quotation
2. Point of Sale (POS)

The note is a transaction-level note for the customer/order.

================================================
1. QUOTATION — ADD NOTE
================================================

Add a clearly visible field:

Note

Recommended UI:
- Place below customer/details section or below item section before totals.
- Use a multiline textarea.
- Optional field.
- Allow normal text.
- Do not make it mandatory.

Example:

Note
[ Customer requested delivery after 5 PM.                 ]
[ Please use frozen packaging.                            ]

The note must be saved with the quotation.

================================================
2. QUOTATION LIST / VIEW
================================================

Do not add a large Note column to the main quotation table.

Instead, when opening/viewing a quotation:

Show:

Note:
<Customer note>

If there is no note:

Do not show an empty large section.

================================================
3. QUOTATION EDIT
================================================

When editing an existing quotation:

- Load the saved note.
- Allow the user to edit it.
- Save the updated note correctly.

Do not lose the note during quotation edits.

================================================
4. QUOTATION PDF / PRINT / SHARE
================================================

Include the Note in:

- Quotation PDF
- Quotation Print
- Quotation preview
- Quotation share/download where applicable

Position it clearly near the bottom of the quotation, preferably:

Notes:
<Customer note>

Do not interfere with:

- Item table
- Subtotal
- Tax
- Other Charges
- Grand Total
- Terms & Conditions
- Signature section

If no note exists, do not display an empty Notes section.

================================================
5. QUOTATION → POS / SALE CONVERSION
================================================

IMPORTANT:

If a quotation is converted into a POS sale:

Quotation Note
        ↓
POS Sale Note

The note must automatically carry forward.

Example:

Quotation:

Customer: ABC
Items: ...
Note:
"Deliver to warehouse gate 2 after 5 PM."

When converted to POS:

Sale Note:
"Deliver to warehouse gate 2 after 5 PM."

The user must still be able to edit the note before completing the sale.

Do NOT create a second duplicate note.

================================================
6. POINT OF SALE — ADD NOTE
================================================

Add a "Note" field in POS.

Recommended placement:

Customer / Sale Details
        ↓
Items
        ↓
Discount / Other Charges
        ↓
Note
        ↓
Totals
        ↓
Payment

The field should be a multiline textarea.

Example:

Note
[ Customer requested delivery tomorrow morning. ]

Optional.

A POS sale can be completed without entering a note.

================================================
7. POS NOTE SAVE
================================================

When the POS sale is completed:

Save the note with the sale.

The note must remain available when:

- Viewing the sale
- Editing where editing is permitted
- Opening the invoice
- Printing
- Downloading PDF
- Sharing invoice
- Viewing sale details

================================================
8. POS INVOICE PDF
================================================

Show the note on the sales invoice PDF.

Example:

Notes:
Customer requested delivery tomorrow morning.

Place it in a clean location that does not disturb the invoice layout.

If there is no note:

Do not show an empty Notes box.

================================================
9. DATABASE
================================================

Inspect the existing quotation and sales schema before making changes.

Prefer adding:

quotation.note
sale.note

or equivalent existing fields if the schema already has a suitable field.

Use the existing database conventions and migrations.

Do NOT duplicate an existing note field.

Do NOT store the note only in frontend state.

The note must persist in PostgreSQL.

================================================
10. API
================================================

Update the relevant APIs for:

Quotation:
- Create
- Update
- Get
- Convert to sale

POS/Sale:
- Create
- Get
- Update where supported

The note must be included in the request/response schema.

Validate:

- string
- optional/null
- reasonable maximum length

Suggested maximum:
2000 characters.

Do not allow uncontrolled unlimited text.

================================================
11. LOCATION / PERMISSION
================================================

The note follows the quotation/sale's existing location and permission rules.

Do not create a separate permission system for notes.

Warehouse users can only access notes belonging to sales/quotations they are authorized to access.

Head Office follows existing location rules.

================================================
12. ACCOUNTING
================================================

IMPORTANT:

The Note is NON-FINANCIAL metadata.

It must NOT affect:

- Sale total
- Tax
- GST
- COGS
- Stock
- Customer outstanding
- Receipt
- Payment
- P&L
- Balance Sheet
- Trial Balance

Adding or changing a note must never create a journal entry.

================================================
13. SEARCH / DISPLAY
================================================

Do not change existing report totals.

Optionally make the note available in the sale/quotation details.

Do not include notes in financial report calculations.

================================================
14. SECURITY
================================================

Escape/safely render note text.

Do not allow HTML/script injection.

The note is plain text.

Line breaks should be preserved in PDF/print where appropriate.
