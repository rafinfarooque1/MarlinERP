General Rules

1. Sidebar and Permission page must contain exactly the same modules in the same order.

2. Names must be identical.

3. Parent sections must be identical.

4. Every sidebar page must have one unique permission key.

5. Every permission key must control only one page.

6. Never let one permission control multiple pages.

7. Every page must have its own:
   - View
   - Add
   - Edit
   - Delete

8. View controls sidebar visibility.

9. Add/Edit/Delete control only operations inside that page.

10. The Sidebar must still be generated from the centralized module registry.

11. The Permission page must also be generated from the same registry.

12. The registry should define one object per page, not one object per permission group.

13. Parent groups (Production, Inventory, Sales, HR, Accounts, Company) are only visual categories and should not be permission keys.

14. Do not hardcode anything in AppLayout or Permissions.

15. The module registry must be the only source of truth.
