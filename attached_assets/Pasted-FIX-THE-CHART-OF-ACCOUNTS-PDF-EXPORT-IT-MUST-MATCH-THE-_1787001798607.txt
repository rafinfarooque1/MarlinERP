2. EXPANSION / COLLAPSE STATE MUST BE RESPECTED
==================================================

This is extremely important.

The PDF must use the EXACT expansion state currently visible on the screen.

If an account/group is collapsed on the screen:
- Do NOT show its children in the PDF.

If an account/group is expanded on the screen:
- Show its children in the PDF.

If nothing is expanded:
- The PDF must show nothing expanded.

If only one particular subgroup is expanded:
- ONLY that subgroup's children should appear.

Do NOT automatically call "Expand All" during PDF generation.

Do NOT generate the PDF from the raw complete account hierarchy.

Do NOT assume all groups are expanded.

The PDF must capture the same hierarchy visibility that the user is currently seeing.

Example:

    > Duty & Tax
    > Sundry Creditors
    > Salary Payable

If user expands only:

    > Duty & Tax
         Output CGST
         Output SGST
         Input CGST
         Input SGST

then the PDF must show exactly that expansion and nothing else.
