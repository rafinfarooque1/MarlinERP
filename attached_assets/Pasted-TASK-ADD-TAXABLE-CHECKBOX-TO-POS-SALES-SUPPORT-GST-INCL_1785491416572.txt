TASK: ADD “TAXABLE” CHECKBOX TO POS SALES — SUPPORT GST-INCLUSIVE B2C AND GST-EXCLUSIVE B2B PRICING

Implement this in the existing Point of Sale / Record Sale / Edit Sale workflow.

Do NOT redesign the entire POS.
Do NOT change purchase pricing.
Do NOT change GST rates stored in Item Master.
Do NOT change inventory/stock deduction logic except where necessary to preserve the correct sale totals.
Do NOT modify existing production sales while implementing/testing.

==================================================
1. REQUIRED UI CHANGE
==================================================

In each POS cart item row, add a small checkbox near the MRP field.

Label:

Taxable

The layout should approximately be:

MRP (₹)
₹200.00

☐ Taxable

Keep it compact and visually aligned with:

Qty | MRP | Taxable checkbox | Discount

The checkbox means:

CHECKED:
“The entered MRP/rate is the TAXABLE VALUE before GST.”

UNCHECKED:
“The entered MRP/rate is the FINAL PRICE INCLUDING GST.”

This distinction is critical.

==================================================
2. AUTOMATIC DEFAULT BASED ON CUSTOMER GSTIN
==================================================

When a customer is selected:

IF customer has a valid/non-empty GSTIN:
    Taxable = CHECKED by default

IF customer has no GSTIN:
    Taxable = UNCHECKED by default

Therefore:

B2B / GST customer
→ checked automatically
→ MRP is treated as taxable/base value
→ GST is added on top.

B2C / customer without GSTIN
→ unchecked automatically
→ MRP is treated as GST-inclusive final selling price
→ taxable value and GST are extracted from the MRP.

For Walk-in Customer:
→ default UNCHECKED.

==================================================
3. USER MUST STILL BE ABLE TO OVERRIDE IT
==================================================

The automatic customer rule is only the DEFAULT.

The user must be able to manually tick/untick Taxable for a sale line when necessary.

Do not permanently lock it based on GSTIN.

If customer changes, recalculate the default intelligently.

Do not unexpectedly overwrite a deliberate user override unless the POS form is being freshly initialized/customer selection genuinely resets the pricing mode.

==================================================
4. CHECKED CALCULATION — GST EXCLUSIVE
==================================================

Example:

MRP / Rate = ₹200
GST = 5%
Taxable = CHECKED

Then:

Taxable Value = ₹200.00
GST = ₹10.00

For intra-state:

CGST 2.5% = ₹5.00
SGST 2.5% = ₹5.00

Grand Total = ₹210.00

So:

CHECKED:
MRP = taxable/base price
GST is ADDED ON TOP.

Formula:

Taxable Value = selling rate after applicable discount
GST = Taxable Value × GST rate
Final = Taxable Value + GST

==================================================
5. UNCHECKED CALCULATION — GST INCLUSIVE
==================================================

Example:

MRP = ₹200
GST = 5%
Taxable = UNCHECKED

₹200 is already the final GST-inclusive price.

Therefore:

Taxable Value =
200 / 1.05
= ₹190.476...

Rounded/displayed appropriately:
₹190.48

GST:
₹200 - ₹190.476...
= ₹9.523...

Displayed:
₹9.52

For intra-state:

CGST = ₹4.76
SGST = ₹4.76

Grand Total = ₹200.00

So:

UNCHECKED:
MRP = GST-inclusive final price
GST must be extracted from the price.

IMPORTANT:
Do NOT calculate:

₹200 - 5% = ₹190

That is mathematically incorrect for extracting included GST.

Correct formula is:

Taxable Value =
Inclusive Price / (1 + GST Rate / 100)

GST =
Inclusive Price - Taxable Value

==================================================
6. DISCOUNT
==================================================

Preserve the existing POS discount behaviour but make it mathematically consistent with the selected pricing mode.

For TAXABLE CHECKED:

Base selling amount
= MRP × Qty - applicable discount

Taxable Value
= discounted base amount

GST
= added on top.

For TAXABLE UNCHECKED:

Final GST-inclusive selling amount
= MRP × Qty - applicable discount

Taxable Value
= discounted inclusive amount / (1 + GST rate)

GST
= discounted inclusive amount - taxable value.

Do not apply discount twice.

Test discount + GST carefully.
