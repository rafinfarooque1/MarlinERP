The current Permission system needs to be redesigned to follow enterprise ERP standards.

The business rule is very clear.

====================================================
PERMISSION RULE
====================================================

Permissions decide ONLY:

• Whether a module is visible.
• Whether the employee can

- View
- Add
- Edit
- Delete
- Download (if applicable)

Nothing else.

====================================================
SIDEBAR RULE
====================================================

If View permission = ON

→ Show the module in the sidebar.

If View permission = OFF

→ Hide the module completely.

No other logic should hide the module.

Remove every hardcoded sidebar visibility rule.

Remove branch-based sidebar hiding.

The Sidebar must depend ONLY on:

Module Registry
+
Permission Resolver

====================================================
DATA ACCESS RULE
====================================================

Permissions DO NOT decide data.

Permissions decide module access only.

Data visibility depends ONLY on employee branch assignment.

====================================================
BRANCH DATA RULE
====================================================

There are only three branch types.

• Head Office
• Warehouse
• Outlet

====================================================
HEAD OFFICE
====================================================

Can see ALL data.

Including

• Production
• Purchases
• Inventory
• Sales
• HR
• Accounts
• Reports
• Customers
• Vendors
• Cash
• All Warehouses
• All Outlets

====================================================
WAREHOUSE
====================================================

Can see ONLY

• Assigned Warehouse

PLUS

• All Outlets mapped to that warehouse

Cannot see

• Other Warehouses

• Other Warehouse Sales

• Other Warehouse Stock

• Other Warehouse Cash

• Other Warehouse Employees

• Other Warehouse Customers

• Other Warehouse Vendors

====================================================
OUTLET
====================================================

Can see ONLY

Assigned Outlet.

Cannot see

• Warehouse

• Other Outlets

• Head Office

====================================================
BACKEND RULE
====================================================

Every API must verify

1. Permission

2. Branch Scope

Permission decides

Can access module

Branch decides

Which records are returned.

Never trust

warehouseId

outletId

locationId

coming from frontend.

Server must determine scope automatically.
