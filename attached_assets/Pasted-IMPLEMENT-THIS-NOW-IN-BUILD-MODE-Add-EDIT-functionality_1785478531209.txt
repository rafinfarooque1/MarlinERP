10. JOURNAL BALANCE VALIDATION
==================================================

A Journal Voucher must always remain balanced.

Required rule:

TOTAL DEBIT = TOTAL CREDIT

Example valid correction:

Before:

Cr Frozen Hub Investment      ₹6,33,194.00

User changes it to:

Dr Frozen Hub                 ₹6,33,192.21
Cr Frozen Hub Investment      ₹6,33,192.21

SAVE should succeed.

Dr Frozen Hub                 ₹6,33,192.21
Cr Frozen Hub Investment      ₹6,33,194.00

SAVE must be rejected.

"Journal voucher is not balanced. Total Debit must equal Total Credit."

Perform this validation on BOTH frontend and backend.
