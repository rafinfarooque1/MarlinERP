IMPLEMENT A COMPLETE LOCATION-AWARE ACCOUNTING AND CASH/BANK SYSTEM.

This is a production ERP. Do NOT break existing accounting, financial data, vouchers, transactions, permissions, or calculations.

The goal is to make location handling consistent across the entire ERP.

============================================================
CORE LOCATION RULE
============================================================

There are two different concepts and they MUST NOT be mixed:

1. ACCOUNT LOCATION ASSIGNMENT
2. TRANSACTION LOCATION

An account can be assigned to one or more locations.

A transaction must always have its own historical location.

Changing an account's location assignment later MUST NEVER modify the location of an old transaction.

============================================================

============================================================

The Cash & Bank module currently allows an account such as:

- Cash
- HDFC Bank
- ICICI Bank
- SBI Bank
- Petty Cash
- Other cash/bank accounts

to have a Location.

Change this so that a Cash or Bank account can be assigned to MULTIPLE locations.

Example:

Allowed Locations:

☑ Head Office

- Head Office

4. TRANSACTION LOCATION IS STILL SINGLE
============================================================

This is extremely important.

Even though a Cash/Bank account can be assigned to multiple locations, EACH TRANSACTION must have ONE actual location.

Example:

HDFC Bank is assigned to:

Head Office
Frozen Hub - Calicut
Frozen Hub - Rajaguda

Transaction 1:

HDFC Bank
Payment ₹50,000
Location = Head Office

Transaction 2:

HDFC Bank
Receipt ₹30,000
Location = Frozen Hub - Calicut

Transaction 3:

HDFC Bank
Payment ₹20,000
Location = Frozen Hub - Rajaguda

These are three separate transactions with three separate locations.

DO NOT store a transaction as belonging to all three locations simply because the account is available in all three.

============================================================
5. HISTORICAL TRANSACTION IMMUTABILITY
============================================================

Changing the Cash/Bank account's allowed locations MUST NOT change old transactions.

Example:

Today HDFC Bank is assigned to:

Head Office
Calicut

Old transaction:

₹50,000
Location = Calicut

Tomorrow administrator removes Calicut from the HDFC Bank account and adds:

Rajaguda

The old ₹50,000 transaction MUST STILL remain:

Location = Calicut

Do not rewrite it.

Do not migrate it.

Do not recalculate it.

Only NEW transactions must follow the new account-location availability.
