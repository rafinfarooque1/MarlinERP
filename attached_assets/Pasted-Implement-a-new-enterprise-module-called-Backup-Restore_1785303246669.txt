Implement a new enterprise module called "Backup & Restore" under the Company module.

Purpose:

Provide a complete disaster recovery solution.

If the application is lost, deleted, corrupted or moved to a new server/Replit, the administrator should be able to restore the ERP using:

1. Source Code (GitHub)
2. Database Backup
3. Company Files
4. Settings

The system should support one-click backup and one-click restore.

==========================================
DISASTER RECOVERY
==========================================

Recovery procedure:

1. Clone ERP source code from GitHub.

2. Create a new PostgreSQL database.

3. Configure environment variables.

4. Open Backup & Restore.

5. Upload the backup ZIP.

6. Restore Database.

7. Restore Files.

8. Restore Settings.

9. Restart the ERP.

After restart, the ERP should be identical to the backup date.
