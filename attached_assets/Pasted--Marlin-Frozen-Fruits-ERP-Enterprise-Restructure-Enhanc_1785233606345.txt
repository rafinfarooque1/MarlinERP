# Marlin Frozen Fruits ERP – Enterprise Restructure & Enhancement

IMPORTANT

Read the existing ERP completely before making any changes.

Do NOT redesign the ERP.

Do NOT change the sidebar navigation.

Do NOT change the existing architecture unless explicitly mentioned.

Preserve the current modules, APIs, permissions, accounting logic, reports, and workflows.

This is an enhancement of the current ERP, NOT a rewrite.

==========================================================
1. ERP STRUCTURE
==========================================================

The ERP will have only two operational location types.

1. Head Office
2. Warehouse

Remove Outlet from the current workflow.

Do NOT delete Outlet from the database.

Instead,

Create a feature flag under Settings.

Enable Outlet = OFF (default)

Future:

If Enable Outlet = ON

then the existing Outlet workflow should work exactly like today.

==========================================================

Do NOT break reports.

Improve the existing ERP.

Maintain enterprise standards similar to SAP Business One, Microsoft Dynamics 365 Business Central, Oracle NetSuite, and Tally Prime, while preserving the current Marlin ERP architecture and workflows.

First produce a complete implementation plan showing affected modules, database changes, API changes, UI changes, workflow changes, and migration strategy. Do not start coding until the implementation plan is complete and approved.
