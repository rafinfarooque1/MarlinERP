TASK: Implement a complete ERP Keyboard Entry Mode (Mouse-Free Data Entry)

The objective is to allow a trained data entry operator to perform all daily ERP transactions using only the keyboard, without touching the mouse.

This should work consistently across the entire ERP and behave like professional ERP software such as Tally Prime, BUSY, Marg ERP, and Focus.

=========================================================
MODULES TO SUPPORT
=========================================================

Implement keyboard navigation for:

• Sales (POS)
• Purchase Bills
• Receipt Voucher
• Payment Voucher
• Journal Voucher
• Contra Voucher
• Credit Note
• Debit Note
• Stock Transfer
• Production Entry
• Expenses
• Quotations

=========================================================
GENERAL KEYBOARD BEHAVIOUR
=========================================================

Every entry form should behave consistently.

When a new form opens:

• Cursor automatically focuses on the first editable field.
• No mouse click should be required.

TAB

Moves to next logical field.

SHIFT + TAB

Moves to previous field.

ENTER

Acts like TAB.

This is the default ERP behaviour.
