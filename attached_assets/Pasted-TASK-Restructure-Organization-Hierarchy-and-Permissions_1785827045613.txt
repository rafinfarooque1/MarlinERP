TASK: Restructure Organization Hierarchy and Permissions

The current hierarchy is:

- Management (currently has full system access)
- Manager
- Owner

This is not correct.

====================================================
NEW HIERARCHY
====================================================

Rename the current "Management" role to:

Administrator (System Admin)

This role is the ERP Super Admin.

Administrator should have FULL ACCESS to everything.

This role should never be restricted.

====================================================

Create a NEW role called:

Management

This represents the company's management team, not the ERP administrator.

Management should NOT have system administration rights.

Management is mainly for monitoring and approvals.

====================================================
NEW HIERARCHY
====================================================

Administrator (Top Level)
        │
        └── Management
                │
                ├── Owner
                ├── Warehouse Manager
                ├── Outlet Manager
                ├── Accounts Manager
                ├── HR Manager
                ├── Sales Manager
                └── Purchase Manager

Employees report to their respective managers.
