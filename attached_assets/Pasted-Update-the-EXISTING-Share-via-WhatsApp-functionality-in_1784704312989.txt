4. IMPORTANT: UNDERSTAND WHATSAPP BROWSER LIMITATIONS
==================================================

Do not incorrectly assume that a normal wa.me URL or WhatsApp URL can automatically attach a local PDF file.

A standard WhatsApp deep link can prefill TEXT but cannot directly attach an arbitrary PDF file automatically.

Implement the best technically correct sharing method depending on the environment.

If the ERP is running in a supported mobile/browser environment:

Use the Web Share API / native share functionality with the generated PDF as a File object where supported.

The PDF should be generated/fetched as a Blob/File with:

MIME type:
application/pdf

Suggested filename:

Invoice-{InvoiceNumber}.pdf

Example:

Invoice-SI-2026-00125.pdf

Open the native share sheet with:
- PDF file
- Invoice sharing text where supported

This allows the user to select WhatsApp and send the actual PDF.

IMPORTANT:
Do not claim that the browser can silently send a WhatsApp PDF without user interaction.

Option A — if the ERP has secure publicly accessible invoice PDF URLs:

"View / Download Invoice PDF"

and open/download the actual invoice.

The link must point ONLY to that customer's/invoice's correct PDF.

Do not expose internal file-system paths.

OR

Option B — if secure PDF URLs are not available:

1. Download/generate the invoice PDF automatically.
2. Open the customer's WhatsApp chat using the existing WhatsApp functionality.
3. Clearly inform the ERP user that the PDF is ready to attach/send.

Do not pretend that a PDF attachment was automatically sent if WhatsApp/browser restrictions prevent it.
