1. The consolidated total for all locations.
2. A location-wise breakdown below the total.

Example:

Sales
Total: ₹10,00,000

Head Office: ₹2,00,000
Frozen Hub - Calicut: ₹4,00,000
Frozen Hub - Rajaguda: ₹2,00,000
Tropicane - Kochi: ₹1,00,000
Tropicane - Ecity: ₹1,00,000

Apply the exact same behavior to all of these dashboard metrics:

- Sales
- Purchases
- Inventory Value
- Expense
- Payables
- Receivables
- Payments
- Receipts
- Cash
- Bank
- Gross Profit (GP)
- Net Profit (NP)

For every metric:

TOTAL = consolidated value across all locations

Below the total, show the amount for each location.

The location-wise amounts must be calculated using the same dashboard date filter currently selected.

Example:

Purchases
Total: ₹5,00,000

Head Office: ₹1,00,000
Frozen Hub - Calicut: ₹2,00,000
Frozen Hub - Rajaguda: ₹50,000
Tropicane - Kochi: ₹75,000
Tropicane - Ecity: ₹75,000

The sum of all location amounts must match the consolidated total wherever the accounting calculation is additive.

## 3. Head Office must behave exactly like a normal location

Head Office is NOT automatically "All Locations".

This is critical.

When the location selector is:

Head Office

Then the entire application must show ONLY Head Office data, exactly the same way selecting a warehouse/location shows only that warehouse's data.

For example, when Head Office is selected:

- Dashboard → Head Office data only
- Sales → Head Office transactions only
- Purchases → Head Office transactions only
- Inventory → Head Office inventory only
- Expenses → Head Office expenses only
- Payments → Head Office payments only
- Receipts → Head Office receipts only
- Cash → Head Office cash only
- Bank → Head Office bank only
- Payables → Head Office payables only
- Receivables → Head Office receivables only
- GP → Head Office calculation only
- NP → Head Office calculation only
- Ledger and reports → Head Office data only

Head Office must behave exactly like:

Frozen Hub - Calicut
Frozen Hub - Rajaguda
Tropicane - Kochi
Tropicane - Ecity

The ONLY difference is that Head Office users may also have the option to select "All Locations".

## 4. "All Locations" is the only consolidated mode

Only when the location selector is explicitly set to:

All Locations

should the system:

- Combine data from all locations.
- Show consolidated totals.
- Show the location-wise breakdown on the dashboard.

Selecting Head Office must NEVER automatically return All Locations data.

If the current implementation treats Head Office as company-wide/global data, fix that behavior.

The filtering logic must clearly distinguish:

HEAD OFFICE SELECTED
→ Head Office data only

WAREHOUSE/BRANCH SELECTED
→ That location's data only

ALL LOCATIONS SELECTED
→ Consolidated data from all locations

Do not only change the label in the UI. The underlying API queries and calculations must return correctly filtered data.
