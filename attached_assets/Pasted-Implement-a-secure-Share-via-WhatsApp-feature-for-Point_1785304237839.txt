Implement a secure "Share via WhatsApp" feature for Point of Sale invoices using a secure PDF download link.

====================================================
MODULE
====================================================

Point of Sale

↓

View Invoice

Add a new button beside

• Print
• Download PDF

New Button

Share via WhatsApp

====================================================
BUSINESS REQUIREMENT
====================================================

When the user clicks "Share via WhatsApp",

the ERP should:

1. Verify the customer has a mobile number.

2. Generate the latest Invoice PDF.

3. Generate a secure public share link for ONLY this invoice.

4. Open WhatsApp with a pre-filled message containing the secure invoice link.

====================================================
CUSTOMER VALIDATION
====================================================

If customer mobile number is empty,

Disable the WhatsApp button.

Display

"Customer mobile number is not available."

====================================================
SECURE INVOICE LINK
====================================================

DO NOT expose invoice IDs directly.

DO NOT use

/invoice/125

Instead create a secure sharing endpoint.

Example

/share/invoice/6fc7a4c89f6b4d8bb5d6f6d82?token=xxxxxxxx

The token must be:

• Random
• Unpredictable
• Unique
• Generated by server
• Stored securely

====================================================
LINK SECURITY
====================================================

Each generated link should have

• Expiry Period: **15 Days**
• Invoice ID
• Token
• Created Date
• Expiry Date
• Status

Status

• Active
• Expired
• Revoked

After 15 days, the link must automatically expire and no longer allow access to the invoice PDF.

====================================================
WHEN LINK IS OPENED
====================================================

Without login,

The customer should only be able to

• View Invoice PDF

or

• Download Invoice PDF

Nothing else.

The page must not expose

• ERP menus
• Dashboard
• API
• Database information
• Customer list
• Other invoices
• Company administration

====================================================

Automatically prepare

Hello {{Customer Name}},

Invoice Date : {{Invoice Date}}

Total Amount : ₹{{Invoice Total}}

====================================================
LINK MANAGEMENT
====================================================

Inside

View Invoice

Provide

• Generate New Link
• Copy Link
• Revoke Link
• Share via WhatsApp

If a valid Active link already exists,

Reuse the existing link instead of creating a new one.

If the existing link has expired,

Automatically generate a new secure link and invalidate the old one.

====================================================
PERMISSIONS
====================================================

Create permission

Invoice WhatsApp Share

Only authorized users can

• Generate Link
• Share Link
• Revoke Link

AUDIT LOG
====================================================

Record

• Invoice Number

• Shared By
• Date
• Time
• IP Address
• Status

====================================================
DATABASE
====================================================

Create table

Invoice Share Links

Suggested fields

• UUID
• Invoice ID
• Secure Token
• Created By
• Created Date
• Expiry Date (15 Days from creation)
• Status
• Access Count
• Last Access Time
• Revoked By
• Revoked Date

====================================================
SECURITY
====================================================

• Never expose sequential invoice IDs.
• Never expose internal database IDs.
• Never expose ERP admin URLs or endpoints.
• Never allow directory browsing.
• Never allow URL manipulation to access another invoice.
• Validate every request on the server before serving the PDF.
• Automatically reject expired or revoked links.
• Return a friendly "This invoice link has expired" page when an expired link is accessed.
