TASK: FIX POS EXISTING-SALE EDIT STOCK VALIDATION

I have reproduced a bug in:

Operations → Point of Sale → Edit Sale

Please implement the fix in development first and do not modify existing production invoices during testing.

PROBLEM OBSERVED

When editing an existing sales invoice, an item can have an original sold quantity greater than the CURRENT available stock.

Example from my recording:

Existing invoice line:
Qty = 60

Current stock available now:
6

The edit form loads Qty = 60 correctly.

I only changed the Discount field.

The invoice totals recalculated correctly.

But when I click "Save Changes", the browser prevents saving and shows:

"Value must be less than or equal to 6."

This is incorrect.

The 60 units already belong to this existing invoice and were already deducted from stock when the invoice was originally created.

The edit screen must NOT validate the entire existing quantity against today's remaining stock.

==================================================
CORRECT EDIT-SALE STOCK RULE
==================================================

For an EXISTING invoice line:

originalQty = quantity currently saved on the invoice
currentAvailableStock = stock currently available excluding this invoice
newQty = quantity entered while editing

Maximum allowed quantity should effectively be:

originalQty + currentAvailableStock

Example:

Original invoice Qty = 60
Current available stock = 6

Maximum editable Qty = 66

Therefore:

60 → 60
VALID
No inventory movement.

60 → 50
VALID
Return 10 units to inventory.

60 → 64
VALID
Deduct only another 4 units from inventory.

60 → 66
VALID
Deduct another 6 units.

60 → 67
INVALID
Only 6 additional units are available.

==================================================
IMPORTANT: USE QUANTITY DELTA
==================================================

Editing a sale must adjust inventory using the difference between OLD and NEW quantities.

delta = newQty - oldQty

If delta = 0:
Do not change stock.

If delta > 0:
Require available stock >= delta.
Deduct only delta.

If delta < 0:
Return abs(delta) units to stock.

Do NOT deduct the entire new quantity again.
