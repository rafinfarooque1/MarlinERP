BANK RECONCILIATION — ONE-STEP RECONCILE WORKFLOW

I want to change the current Bank Reconciliation workflow to a SIMPLE ONE-STEP PROCESS.

CURRENT PROBLEM:
The user currently has to go through/open the Reconciliation page to reconcile a bank transaction.

REQUIRED NEW BEHAVIOUR:

From the Bank Book / Bank Account transaction list:

[ ] Reconcile

The user should be able to simply TICK the Reconcile checkbox.

Once the checkbox is ticked:

1. The transaction is immediately marked as RECONCILED.
2. The reconciliation is saved to the database immediately.
3. No separate Reconciliation page should be required.
4. No second "Save Reconciliation" step should be required.
5. No navigation to another page should be required.
6. The row should immediately show the reconciled status.
7. The bank reconciliation balance/status should update immediately.
8. The action must be atomic and server-side validated.
9. Show a small success confirmation such as:
   "Transaction reconciled successfully."

==================================================
1. BANK BOOK UI
==================================================

In the Bank Book / Bank Account transaction list, add/use:

[ ] Reconcile

When unchecked:
Transaction is NOT reconciled.

When checked:
Transaction is RECONCILED immediately.

The checkbox must reflect the actual database status.

Do NOT make this only a frontend visual checkbox.

==================================================
2. ONE-CLICK RECONCILIATION
==================================================

When user clicks:

[ ] Reconcile

Frontend must call a dedicated backend API such as:

POST /api/bank-reconciliation/reconcile

or reuse the existing reconciliation endpoint if one already exists.

Backend must:

- authenticate user
- verify permission
- verify bank account access
- verify transaction access
- verify location access
- verify transaction is eligible for reconciliation
- update reconciliation status
- record reconciliation date/time
- record reconciled user
- create audit log
- return updated transaction

All changes must be persisted immediately.

==================================================

IMPORTANT:

After clicking Reconcile:

DO NOT redirect the user to:

/reconciliation

Do NOT open a new page.

Do NOT require the user to leave Bank Book.

The user remains on the current Bank Book screen.

Example:

Bank Book

Transaction 1   ₹10,000   [✓ Reconciled]
Transaction 2   ₹5,000    [ ] Reconcile
Transaction 3   ₹2,500    [✓ Reconciled]

The user can continue ticking transactions directly.
