Implement enterprise-grade column sorting across every data table in the ERP.

The behavior should be exactly like Excel, Tally Prime, SAP Business One, Zoho Books, and ERPNext.

Requirements

1. Every table listing records should support sorting by clicking the column header.

Examples:
- Sales
- Purchase Bills
- Quotations
- Receipt Vouchers
- Payment Vouchers
- Journal Vouchers
- Contra Vouchers
- Credit Notes
- Debit Notes
- Customers
- Vendors
- Employees
- Stock
- Item Master
- Batches
- Production
- Expenses
- Cash Book
- Bank Book
- Day Book
- Ledger Statements
- Trial Balance
- Reports
- Every other grid/table in the ERP.

2. Clicking a column header should sort the ENTIRE ROW, not just that column.

Example:

Invoice | Date | Customer | Total

The invoice, customer, amount, status, tax, location and every other field should move together as one record.

3. Sorting behavior

First click
Ascending ↑

Second click
Descending ↓

Third click
Return to Default ERP Order (optional but preferred).

Location = Ragiguda

If search returns 15 rows

sorting should reorder only those 15 rows.

Page 1

Page 2

Page 3

must remain correct.

10. Server-side sorting

Large tables should use server-side ORDER BY instead of downloading every record.

11. Performance

Sorting should remain fast even with

100,000+

records.

12. Default order

When no sorting is selected,

continue using the existing ERP default ordering.
