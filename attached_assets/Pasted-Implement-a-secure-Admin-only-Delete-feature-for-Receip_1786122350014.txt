Implement a secure Admin-only Delete feature for Receipt Vouchers and Payment Vouchers.

This is a HIGH-RISK accounting operation and must be implemented carefully.

====================================================
1. Admin Only
====================================================

Only users with Administrator permission can see the Delete button.

Normal users must never see or access it.

This applies to:

• Receipt Voucher
• Payment Voucher

====================================================
2. Only System Generated Vouchers
====================================================

The Delete button should ONLY appear for system-generated vouchers.

Examples:

✓ Receipt generated from Sales Payment
✓ Receipt generated from POS
✓ Receipt generated from Customer Payment
✓ Payment generated from Purchase Payment
✓ Payment generated automatically by ERP

Do NOT allow deletion of manually entered vouchers through this feature.

Manual vouchers will continue using the normal accounting workflow.

====================================================
3. Confirmation Dialog
====================================================

When Admin clicks Delete,

Show a large warning dialog.

Title:

Delete System Generated Voucher

Warning:

This operation will permanently remove the voucher and reverse every accounting effect created by it.

The following records will be updated:

✓ Voucher
✓ Ledger Entries
✓ Customer/Vendor Ledger
✓ Cash/Bank Ledger
✓ Party Balance
✓ Dashboard
✓ Trial Balance
✓ Balance Sheet
✓ Profit & Loss (if affected)
✓ Cash Book
✓ Bank Book
✓ Day Book
✓ Payment History
✓ Invoice Status
✓ Outstanding Amount
✓ Receivable/Payable
✓ Audit References
✓ Location Reports

This action cannot be undone.

====================================================
4. Show Exactly What Will Change
====================================================

Before deletion calculate and display:

Voucher Number

Voucher Date

Party Name

Location

Amount

Linked Invoice

Cash/Bank Account

Ledger Entries

Then display:

The following actions will be performed:

✓ Voucher deleted

✓ Vendor balance updated

✓ Cash/Bank balance updated

✓ Invoice payment removed

✓ Invoice status recalculated
(Paid / Partially Paid / Unpaid)

✓ Outstanding recalculated

✓ Dashboard refreshed

✓ Reports recalculated
