Redesign the existing Import module into a step-by-step ERP Migration Wizard.

The current Import UI should be removed and replaced with a guided workflow.

The workflow must be linear. The user cannot skip steps.

==========================================================
STEP 1 – Upload Migration Files
==========================================================

Create a single "Migration" screen.

Show upload cards in this order:

1. Sales
   [Upload File]

2. Purchase
   [Upload File]

3. Receipt
   [Upload File]

4. Payment
   [Upload File]

5. Day Book
   [Upload File]

Each card should show:

✓ File uploaded
Rows detected
Transactions detected
Errors
Warnings

The user should be able to replace an uploaded file before continuing.

Only when all required files are uploaded should the "Next" button become enabled.

==========================================================

Invalid amounts

STEP 4 – Demo Import
==========================================================

Store the old voucher number as

Legacy Voucher Number.

==========================================================

✓ Vendor Outstanding

✓ Cash Book

✓ Bank Book

No production data should exist.
