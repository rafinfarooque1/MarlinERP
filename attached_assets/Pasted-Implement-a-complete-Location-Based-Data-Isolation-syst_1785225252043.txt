Implement a complete Location-Based Data Isolation system across the entire ERP.

This is NOT related to the Permission module.

Permissions only control:
- Module visibility
- View
- Add
- Edit
- Delete

Location-Based Access Control (LBAC) must work independently from permissions.

===========================================================
MASTER RULE
===========================================================

Every employee must ONLY see, create, edit, search, print, export, and report data belonging to the location assigned in Employee Creation.

The assigned location determines data visibility everywhere in the ERP.

Never rely on frontend filtering.

All filtering must be enforced on the backend.

===========================================================
USER TYPES
===========================================================

1. Head Office
Can:
- View all warehouses
- View all outlets
- View all head office data
- Transfer between all locations
- Edit all locations
- See all reports
- See all customers
- See all vendors
- See all stock
- See all accounts
- See all ledgers

2. Warehouse User
Can:
- View ONLY their assigned warehouse
- View outlets under that warehouse (if applicable)
- Cannot see other warehouses
- Cannot see other warehouse customers
- Cannot see other warehouse vendors
- Cannot see other warehouse stock
- Cannot edit another warehouse

3. Outlet User
Can:
- View ONLY their assigned outlet
- Cannot see warehouse data
- Cannot see head office data
- Cannot see other outlets

===========================================================
EMPLOYEE LOCATION
===========================================================

Employee Creation already contains:

- User
- Role
- Assigned Location

Use Assigned Location as the master filter throughout the ERP.

===========================================================
GLOBAL RULE
===========================================================

Every page
Every API
Every report
Every search
Every export
Every dashboard
Every dropdown
Every lookup
Every popup
Every autocomplete
Every print
Every PDF

must automatically filter using the employee's assigned location.

===========================================================
CUSTOMERS
===========================================================

If Warehouse A creates a customer:

Only:
- Warehouse A
- Head Office

can see that customer.

Warehouse B cannot.

Warehouse C cannot.

Outlets cannot.

Likewise:

If Outlet creates customer:

Only:
- That outlet
- Head Office

can access.

===========================================================
VENDORS
===========================================================

Same rule.

Vendor created by Warehouse A

Visible only to:
- Warehouse A
- Head Office

===========================================================
STOCK
===========================================================

Warehouse users:

Must only see stock belonging to their warehouse.

Never show stock from:
- Head Office
- Other Warehouses
- Other Outlets

Outlet users:

Only their outlet stock.
