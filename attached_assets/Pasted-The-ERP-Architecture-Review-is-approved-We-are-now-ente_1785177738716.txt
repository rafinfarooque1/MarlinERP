=========================================================
1. RBAC & PERMISSION SYSTEM (HIGHEST PRIORITY)
=========================================================

The Permission system must become the single source of truth.

Permission controls:

• Module visibility
• View
• Add
• Edit
• Delete
• Download

Branch never controls module visibility.

Branch only controls DATA.

Required behavior:

Head Office
→ Can see every permitted module.
→ Can access all company data.

Warehouse
→ Can see every module allowed by permission.
→ Can access ONLY:
   • Assigned warehouse
   • Mapped outlets

Outlet
→ Can see every module allowed by permission.
→ Can access ONLY:
   • Assigned outlet

Module Visibility Rules

View = ON
→ Module visible.

View = OFF
→ Module hidden.

No hardcoded sidebar logic.

No branch-based hiding.

Backend must enforce the same permission rules.

Every GET endpoint must validate View permission.

Every POST endpoint must validate Add.

Every PATCH endpoint must validate Edit.

Every DELETE endpoint must validate Delete.

Permission checks must exist on frontend and backend.

Frontend only hides UI.

Backend always enforces security.
