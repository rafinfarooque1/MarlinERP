MASTER ERP UI/UX MODERNIZATION + STORAGE LOCATION REDESIGN

OBJECTIVE

Completely modernize and improve the UI/UX of the entire existing Marlin ERP.

The ERP should look and behave like one professional, modern, production-grade ERP system across every module.

Use the existing ERP functionality, backend, accounting engine, database, permissions, calculations and workflows as the source of truth.

IMPORTANT:
This task is primarily a UI/UX modernization.

DO NOT break or rewrite working business logic.

DO NOT change existing accounting calculations unless a genuine bug is discovered.

DO NOT change existing ledger posting rules.

DO NOT change GST calculations.

DO NOT change stock calculations.

DO NOT change customer/vendor balances.

DO NOT change voucher numbering.

DO NOT change month-locking rules.

DO NOT change B2B/B2C logic.

DO NOT change payroll calculations.

DO NOT change import/migration logic.

The new UI must use the existing backend and services wherever possible.

If backend changes are required for the new Storage Location/Sub-location functionality, implement them properly and test them.
