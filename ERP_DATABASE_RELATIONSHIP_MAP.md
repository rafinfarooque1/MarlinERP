## Scope and interpretation

This is a source review of the base Drizzle DDL, raw boot migrations, and owning routes/services. “FK declared” reports what was found in inspected source DDL; it does not certify that the same constraint exists in a live database. `NO` means no explicit foreign-key declaration was found for the relation described. Application joins, triggers, polymorphic keys, and JSON line identities are called out separately.

Several schema objects are added with raw SQL. Constraints embedded in `CREATE TABLE IF NOT EXISTS` do not prove that an existing database received the constraint; see `ERP_CURRENT_ISSUES_REGISTER.md` for DDL drift. No database was queried for this map.
