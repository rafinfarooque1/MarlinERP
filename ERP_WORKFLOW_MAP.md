## Scope

This map summarizes source-evidenced UI → API/service → persisted data → accounting/inventory/GST/audit/report relationships for the requested business flows. A source link indicates that the implementation path was found; it does not prove successful runtime behavior, every caller, every write side effect, or production data state. `NOT VERIFIED` is retained where source review did not establish the full chain.

## Cross-cutting limits

- The shared activity log uses both transaction-bound and best-effort paths; the audit function determines whether failure rolls back a business mutation. This map does not enumerate every mutation/audit call site.
- Accounting is derived from source documents plus journal lines; there is no single universal persisted posting table for every business event.
- The map does not establish production data, runtime reachability, external-service behavior, or test pass status.
- Purchase Request/Order and transfer cancellation must remain “not found in inspected routes” rather than being asserted absent from the entire product.
